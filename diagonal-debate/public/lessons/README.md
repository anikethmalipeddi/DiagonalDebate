# Lesson PDFs

Store lesson PDFs here with descriptive, lowercase filenames, such as `argument-construction.pdf`.

To add a lesson, copy the PDF into this folder and update `lessonFiles` in [`app/lessons/page.tsx`](../../app/lessons/page.tsx). Add its display title to `lessonTitles` and check the lesson metadata on the page. The browser URL is `/lessons/<filename>.pdf`.

Files in this directory are public assets. A hidden toolbar or disabled right-click does not stop someone from downloading or sharing a PDF. Only add materials you have permission to distribute publicly.
